Task 2 - Media Queries

Media queries can be used to ensure that CSS rules only apply to certain clients (e.g., desktop, mobile, etc.). We will look at some simple media queries using the provided form-validation.html from Canvas:

  1. Create a style.css file and link it to the HTML document using the link tag.
  2. In the stylesheet, add the following code:
    @media (max-width: 600px) {body {color: yellow;}}
    @media (min-width: 601px) {body {color: green;}}
  3. Adjust the width of the browser and watch how the text colour changes depending on which media query evaluates to true.
  4. Write a media query to make the text size larger on mobile devices (Hint: Use @media (hover: none) to target mobile devices.) Through the Inspector, check whether your query works by using the 'Toggle device emulation' button (second button on top left) to switch to mobile phone emulation.
  5. Write a media query to change the background colour when the viewport width is less than the viewport height (i.e., portrait view). Hint: Use min-aspect-ratio or max-aspect-ratio in your query.

Task 3 - Stress Test (Optional)

An important part of HCI testing is to have other people look at your design, as what seems obvious to you may not be so obvious to others.

Task 4 - Lighthouse Analysis (Optional)

Chromium-based browsers (e.g., Microsoft Edge and Google Chrome) have an additional tool in their Inspector called 'Lighthouse', which can check many of the common speed, search, and usability issues with websites.

  1. Open a Chromium-based browser with extensions disabled (so they don't impact the results of the test). You can do this by opening the browser with the flag --disable-extensions. For example, Microsoft Edge can be launched using msedge.exe --disable-extensions.
  2. Open the HTML document in Task 2 in this new browser window. Open the Inspector and select the 'Lighthouse' tab.
  3. Run a scan in both Desktop and Mobile modes over all categories (except Progressive Web App). Take note of the results.
  4. Make adjustments to the page and try to increase the score in each category to 100% as a practice. Note that for our course, you may ignore the HTTPS and CSP issues under the 'Best practices' category.
