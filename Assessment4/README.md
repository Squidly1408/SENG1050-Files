## Format

19 questions: Section A 10 MCQs (20 marks, GPAS answer sheet), Section B 6 short-answer questions (50 marks), Section C 3 long-answer questions (30 marks). Sections B and C go in a 12-page answer booklet. One A4 double-sided memory aid and a non-programmable calculator are allowed.

## Coverage

Lectures 1-12 (see the [root README](../README.md) for the week list). The review says to go through all slides marked with a star, emphasise starred topics, revisit lab content, and put HTML, XML, CSS, PHP and JavaScript syntax on the memory aid. Lab tasks labelled 'Not in Exams' (e.g. RSA, steganography, GZIP) are not examined; Huffman and CRC are labelled '100% in Exams'.

## Pitfalls

- Overall 50%+ but under 40% in the exam gives a Criterion Fail (FF); at 25%+ a capped supplementary assessment (max 50% of that item) is possible.

## Flags

- The outline says the exam can be reattempted with no feedback, while the review slides describe the supplementary rule above. Check Canvas for the current rule.
