Task 1 - HTML Forms

In this task, you are going to use HTML form elements and attributes to create a simple form for submitting information to a web server. Note that you need not know how the CGI script is working. The main aim of this task is for you to become familiar with the various HTML form elements, to help you create forms for the assignments.

  1. Make a new copy of your template.html file from Lab 2 and open it in your favourite plain-text editor (e.g., notepad or textpad).
  2. After adding an appropriate title and level-1 heading, insert form tags into the body of your document: 
    <form>
</form>
  3. In the opening of the form tag, include the attributes method="post" and action="https://jkorpela.fi/cgi-bin/echo.cgi".
  4. Within the form, place elements to accept the following information:
    • The applicant's first name (<input type="text">, include the placeholder="First name only" and required attributes)
    • The applicant's last name (similar to first name)
    • The applicant's date of birth (<input type="date">, include the required attribute)
    • The applicant's age (<input type="number">, include the min, max, and value attributes to set the minimum, maximum, and default ages)
    • The applicant's email (<input type="email">, include the placeholder and required attributes)
    • The applicant's website (<input type="url">, include the placeholder attribute)
    • The applicant's phone number (<input type="tel">, include the placeholder and required attributes)
    • The applicant's skill level (<input type="range">, include the min="1", max="10", and value="1" attributes)
    • The applicant's address (<textarea>, include the rows="5" and required attributes)
    • The applicant's postcode (<input type="text">, include the size="4" and maxlength="4" attributes)
    • The applicant's state (<select> and <option>. Use one <option> tag for each of the states (NSW,QLD,SA,TAS,VIC,WA) )
    • The applicant's card type (create three <input type="radio"> buttons; include the name attribute to ensure that only one of the three card types (visa,mastercard,amex) can be chose; set visa to be the default choice using the checked attribute)
    • The name on the card (similar to first name/last name)
    • The card number (<input type="number">)
    • The card's security code (<input type="number">, include the min="001" and max="999" attributes to enforce the security code to be a 3 digit positive number)
    • The card's expiry date (<input type="month">)
    • For each form control, associate a label with the <label> tag (use explicit labelling).
    • Group the form controls into four groups with <fieldset> and <legend> tags as shown in the following figure.
    • There should also be a button to submit the form, and a button to reset the form.

Task 2 - HTML Tables

In this task, you are going to use an HTML table to display some statistical data from the web.

  1. Make a new copy of your template.html file from Lab 2 and open it in your favourite plain-text editor.
  2. After adding an appropriate title and level-1 heading, insert table tags into the body of your document: 
    <table>
</table>
  3. Inside the table tags, insert the <thead>, <tbody> and <tfoot> tags (they must be in that order and don't forget each corresponding closing tags).
  4. Access the Distribution of Top-Level Domain Names by Host Count, January 2013 page hosted by the Internet Systems Consortium. You will use the data from this site (just the first 6-7 rows will do) to create your table.
  5. In the head (<thead>) of your table , create a row (<tr>) for the headings of the table.
    Populate each cell (column) of this row using the table heading (<th>) tag.
    You will use the content from row 1 of the original data.
  6. In the body (<tbody>) of your table , create the necessary rows (<tr>) for the data of the table.
    Populate each cell (column) of these rows using the table data (<td>) tag.
    You will use the content from row 3 to 7 of the original data.
  7. In the foot (<tfoot>) of your table , create a row (<tr>) for the foot of the table.
    Populate each cell (column) of this row using the table data (<td>) tag.
    You will use the content from row 2 of the original data.
  8. Finally, add an appropriate <caption> to the table, which includes a hyperlink to the source of the original data.

Now, you can add visual formatting suggestions for your table using embedded CSS styles.

  1. In the content of the <head> tag, place a CSS <style> tag:

  2. Inside this <style> tag, add CSS rules to suggest visual formatting for your tables. Try to replicate the styling of the table in the figure below:
    • You will have to add class attributes to some tags to differentiate certain rows and columns.
    • You should at least change the text alignment of the numbers to be right aligned, without changing the alignment of the rest of the table's cells (hint: apply text-align: right to the body and footer of the table. Then, override the cells in the first column of the table and the last column of the body of the table with text-align: left.
