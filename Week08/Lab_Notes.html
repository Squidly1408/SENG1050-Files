Task 2 - Write a Form Validation Script

Much time and bandwidth can be saved by performing simple checks on a form at the client side before the form is transmitted.

Download the provided form-validation.html from Canvas and attempt the following.

  1. Calculate the length of a text string. From the lecture notes, make use of document.getElementById("id").value.length. Use document.write() to print out the length of the user's name as entered in the form.
  2. Write a JavaScript expression to validate that one and only one of the checkboxes was selected from easyform (name of the form provided). As a guide, use the following logic. Let A be the event for "no boxes are checked at all" and B be the event for "more than 1 box is checked". If (A OR B), then it is not the case that one and only one box was checked, thus we issue and alert and return false. Otherwise, we thank the user and return true.
  3. Check that a textbox contains only numerical data. Add a new text input to the form and write a JavaScript function to check that the input is numerical. In your function, you can make use of the following variable which allows a regular expression (regex) check:
    var pattern = /^-?\d+(\.\d+)?$/;
    The interpretation is;
    ^-? At the start of the string you may have a minus sign
    \d+ Then you will have one or more digits
    (\.\d+)? Then, optionally, a decimal point followed by one or more digits
    $ Then the string ends.
    To test, use var a = pattern.test(document.getElementById("id").value) and check to see if a contains "true" or "false".
  4. Calculate the position of a character within a string. JavaScript's indexOf allows us to determine the position of a character (or even a substring) within a string of text. For example,
    var a = "1 1 was a racehorse, 2 2 was 1 2. 1 1 1 1 race 1 day, 2 2 1 1 2.";
    var b = a.indexOf("w");
    The value of the variable b is now 4 (remember JavaScript begins counting from 0).
    Choose a character from the textbox with identity "id" above and use indexOf to determine its position. If the character cannot be found, indexOf will return the value -1.
    Note that these exercises can be used as a starting point for the validation task in your assignment.

Task 4 - Working with the DOM (Challenging - May refer to sample solution)

As you may have noticed from Task 2, using document.write wipes the entire page, leaving only what you specifically passed to the document.write method. This is rarely the desired result.
Instead, we generally want to work with the elements that already exist on the page, or create our own in a particular position on the page.

  • Before an element can be added, it must first be created. Use document.createElement("tagname") to create a new element (make sure to assign it to a variable!
  • You can then position the new element in the DOM by selecting the element that it should be positioned in relation to and using the insertAdjacentElement method. For example, to insert a new text input after the reset button the following code could be used:
    var newInput = document.createElement("input");
    newInput.type = "text";
    newInput.name = "newtext";
    document.easyform.insertAdjacentElement("beforeend", newInput);
  • Each element in the DOM has a remove() method that will remove it from the DOM. For example, to remove the text input we created next to the reset button, we could use:
    document.easyform.newtext.remove();
